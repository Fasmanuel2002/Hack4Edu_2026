Why it shaped this project

A small model fails alone. Given the right text, it does not.

In the paper's results, Gemma 3 (4B), the model we use, scores close to zero when it must translate or solve math in African languages by itself. But when it is handed a passage and asked a question about it, it comes within about a point of GPT-4.1. Twins for Change is built on that gap: it retrieves verified bilingual examples and gives them to Gemma, so it reads before it answers.
